What it is

One isolated browser, routed through your tunnel

Some pages change with the country: prices, language, offers, availability. To check them, Claude has to look from there, through a real exit in that country.

What it does

  • Runs a dedicated remote Chromium on your Linux server.
  • Routes that browser's traffic through a WireGuard gateway.
  • Lets Claude pick the country, check the exit IP and open public pages.
  • Returns the address, the title and the HTTP status of each page.

What it does not change

  • The IP address of Claude.ai.
  • Anthropic's network.
  • The IP address of your computer or phone.
  • Any traffic outside the managed browser.

Localisation checks

See which language, currency and copy a page shows in each country.

How it works

Control outside, traffic inside the tunnel

The MCP control plane stays outside the VPN. The browser worker shares the VPN gateway's network namespace, so its outbound traffic uses the tunnel.

Clauderemote MCP connector
MCP serverStreamable HTTP, bearer token, behind your HTTPS proxy
Browser workerFastAPI + Playwright Chromium
WireGuard gatewaygluetun, firewall on
Internetexit in the chosen country
shared network namespace: the browser can only go out through the tunnel
Tools

Five functions Claude can call

You never call them yourself. You write what you need, and Claude chooses.

vpn_locations

Lists the countries that have a VPN exit and a browser, and the default one.

() → locations, default
vpn_status

Checks the remote browser and its public exit IP.

(country) → worker, vpn_ip
vpn_connect

Selects the browser routed through that country's gateway, and refuses if no exit IP can be verified.

(country) → connected, vpn_ip
vpn_disconnect

Stops the remote browser. The VPN gateway stays on, so no traffic leaks outside the tunnel.

(country) → browser stopped
browser_open

Opens a public HTTP or HTTPS address in the remote browser.

(url, country) → url, title, http_status

Safety built in

Token on every call, localhost-only MCP port, local and private destinations blocked, page content marked as untrusted.

Safety

What the kit already protects

  • Secret bearer tokenEvery MCP call and every call to the worker needs it. Only the health check is open.
  • Localhost-only MCP portCompose binds the MCP service to 127.0.0.1:8080. You publish it through your own HTTPS proxy.
  • Only public HTTP and HTTPSOther schemes are refused with a 400.
  • Local and private IPs blockedlocalhost and private, loopback and reserved IP addresses are refused with a 403.
  • Gateway stays onDisconnecting stops the browser, never the tunnel, to avoid leaks.
  • Untrusted pagesPages can contain prompt injection. The kit returns only address, title and status, with a note that content is untrusted.
Setup

From zero to a connector in Claude

The software is free and open source. The VPS, the domain and the VPN exit servers may cost money.

Linux VPS with Docker Compose v2 and /dev/net/tunWireGuard client profile for each countryPublic HTTPS endpoint on port 443A provider that allows browser traffic

Add your WireGuard profile

Copy the example profile to vpn/profiles/it.conf and replace it with the real client configuration of an exit server in Italy.

Set a long random token

cp .env.example .env
# set MCP_API_TOKEN in .env

Start the stack

docker compose up -d --build
curl http://localhost:8080/health

Connect it in Claude

Put the MCP endpoint behind HTTPS, then in Claude open Settings, Connectors, Add custom connector, and enter https://YOUR_DOMAIN/mcp with bearer-token authentication.

Add more countries

Duplicate the vpn_it and browser_it services with a new profile, then add the worker to BROWSER_WORKERS. Each country needs a real exit server there.

BROWSER_WORKERS={"it":"http://vpn_it:3001","de":"http://vpn_de:3001"}

Limits

It is a starter kit

The same limits written in the project README, plus what we noticed while reviewing the code.

One session

One browser session at a time, shared by every call.

One country by default

More countries need more services, profiles and real exit servers.

Title and address only

browser_open does not return page contents or screenshots.

Not an anonymity proof

vpn_status shows the public exit IP. It does not prove anonymity or protect other traffic.

Your exit, your upkeep

You provide and maintain the WireGuard exit server and its profile.

Names and redirects

The block on private destinations checks literal IP addresses. Host names that resolve to private addresses, and redirects, are not checked yet.

Before offering it to other users, add:OAuthper-user authorisationrate limitsaudit logsDNS leak testsa kill switch

Do not sign in to personal accounts or enter sensitive credentials in this browser. Do not use random free VPN endpoints for sensitive browsing.

FAQ

Questions

Does it change Claude's IP address?

No. Claude.ai, Anthropic's network and your own device keep their addresses. Only the isolated browser managed by this project goes out through the tunnel.

Can I choose any country?

Only countries where you have a real WireGuard exit server. A country label alone does not create geographic routing.

Does Claude see the page content?

Not in this version. Claude receives the final address, the page title and the HTTP status. Reading content and screenshots are not part of the starter kit.

Is it free?

The software is free and open source. A VPS, a domain and VPN exit servers may cost money.

Is it safe to log in to my accounts with it?

No. Treat it as an MVP: do not sign in to personal accounts and do not type sensitive credentials in the remote browser.

Is this made by Anthropic?

No. Claude VPN MCP is an independent project by MoniliAI. It connects to Claude as a custom MCP connector.
