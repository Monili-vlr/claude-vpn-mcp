How it works

One gateway and one browser for each place

When you ask for a place, the server starts a WireGuard gateway filtered to that place and an isolated browser that shares its network. Only that browser goes through the tunnel.

Claudeyour chat, with the connector
MCP serverHTTPS, bearer token, starts and stops places
Gatewaygluetun with your VPN provider, firewall on
Browserisolated Chromium, Playwright
Internetfrom the place you asked for
one pair for each active place, up to three at a time

The place is verified, not assumed

After starting, the browser geolocates its own exit IP with two independent services. If the exit is somewhere else, the gateway is restarted and the provider picks another server, up to three times. Otherwise Claude tells you why it could not.

Docker, behind a guard

The server starts containers through a socket proxy that allows only container and network operations, never the raw Docker socket.

Safety

What the kit already protects

  • Secret bearer tokenEvery MCP call and every call to a browser needs it. Only the health check is open.
  • Localhost-only server portThe MCP service listens on 127.0.0.1:8080. You publish it through your own HTTPS proxy.
  • Only public HTTP and HTTPSOther schemes are refused with a 400.
  • Local and private IPs blockedlocalhost and private, loopback and reserved IP addresses are refused with a 403.
  • No leaks on turn offThe browser is removed before its gateway, so it never goes online outside the tunnel.
  • Untrusted pagesPages can contain prompt injection. Only address, title and status come back to Claude.
Setup

Set up once, then just write

Whoever hosts the kit does this once, in about ten minutes. After that, every place is a prompt. The software is free and open source; the server and the VPN subscription may cost money.

A Linux server with DockerA VPN subscription with WireGuard (for example Mullvad, Proton VPN, NordVPN, Surfshark)An HTTPS address

Run the installer

It asks a few plain questions: your VPN provider, its WireGuard key and, if your provider gave you one, an address. It generates the secret token by itself.

./install.sh

Add the connector in Claude

Settings, Connectors, Add custom connector, then https://YOUR_DOMAIN/mcp with the token the installer printed.

Write

"Activate my location in California." That is all.

Limits

It is a starter kit

One browser per place

Up to three places at a time by default.

Title and address only

browser_open does not return page contents or screenshots.

Geolocation is a database

The place check is as good as the geolocation services behind it.

Your provider sets the map

A place works only if your VPN provider has servers there.

Not an anonymity proof

The status shows where the exit is. It does not prove anonymity.

Names and redirects

Private destinations are blocked by IP address. Host names that resolve to private addresses, and redirects, are not checked yet.

Before offering it to other users, add:OAuthper-user authorisationrate limitsaudit logsDNS leak testsa kill switch

Do not sign in to personal accounts or enter sensitive credentials in this browser.

FAQ

Questions

Do I need to be a programmer?

No. Day to day you only write to Claude. The one-time setup is a single installer that asks plain questions; whoever hosts the kit runs it once.

Which places can I ask for?

Any place where your VPN provider has servers. US states, many countries and some cities are known by name, also in Italian and Spanish. Every place is verified by geolocating the exit.

Which traffic goes through the tunnel?

Only the traffic of the browser started for that place. Everything else, Claude included, keeps its usual connection.

Does Claude see the page content?

Not in this version. Claude receives the final address, the page title and the HTTP status.

Is it free?

The software is free and open source. A server and a VPN subscription may cost money.

Is this made by Anthropic?

No. Claude VPN MCP is an independent project by MoniliAI. It connects to Claude as a custom MCP connector.
